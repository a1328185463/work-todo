# 云上待办清单 · Cloud Todo

一个零依赖、离线可用的纯前端待办清单应用：深色主题、键盘友好、数据保存在浏览器本地。

## 功能

- 新增待办（回车或点击「添加」）
- 勾选完成 / 取消完成
- 删除单条待办
- 按「全部 / 进行中 / 已完成」筛选，并实时统计数量
- 一键清除已完成
- 使用 `localStorage` 持久化，刷新不丢数据

## 技术栈

- 原生 HTML + CSS + JavaScript（无构建、无第三方依赖）
- 存储：`localStorage`（key：`cloud-todo-items-v1`）

## 本地运行

任选一种方式在项目根目录启动静态服务：

```bash
python3 -m http.server 8080
# 或者
npx serve .
```

然后浏览器打开 <http://localhost:8080/>。

也可以直接双击 `index.html` 打开（不依赖服务端）。

## 目录结构

```
work-todo/
├── index.html   # 页面结构
├── style.css    # 深色主题样式
├── app.js       # 业务逻辑与本地存储
└── README.md
```

## 设计说明

- 状态只有「未完成 / 已完成」两态，避免复杂的项目管理概念；
- 所有渲染通过 `render()` 单点重绘，数据与视图保持单向同步；
- 存储写入失败时静默降级（如隐私模式），不影响当前会话使用。
